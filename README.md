# Schaduwcrypte

Diablo-achtige actie-RPG, gemaakt als installeerbare PWA voor Android (landscape, touch-eerst). Werkt ook in de browser met muis en toetsenbord.

## Spelen

- **PWA in de browser:** [https://droplul.github.io/schaduwcrypte/](https://droplul.github.io/schaduwcrypte/)
- Op je telefoon: open de link in Chrome, tik op menu ⋮ → **Toevoegen aan startscherm**.
- **Android-APK:** [schaduwcrypte-1.0.apk](https://droplul.github.io/schaduwcrypte/downloads/schaduwcrypte-1.0.apk) (of via [GitHub Releases](https://github.com/Droplul/schaduwcrypte/releases)). Installeer vanaf onbekende bronnen is nodig omdat deze APK niet uit de Play Store komt.

## Besturing

- Telefoon: joystick links, aanvalsknop en spreuk (Hellevuur) rechts, levens- en manadrank daarboven. Tik op de grond om te lopen of op een vijand om aan te vallen.
- Toetsenbord: WASD of pijltjes, spatie = aanval, Q = spreuk, 1/2 = drankjes, Esc = pauze.

Voortgang wordt lokaal op het apparaat bewaard.

Pakketnaam van de APK: `nl.schaduwcrypte.app`. Minimaal Android 7 (API 24), gericht op API 36. Landscape.
